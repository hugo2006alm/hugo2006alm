## 🚀 Featured Work

### 📚 [AntiRecurso](https://github.com/Nucleo-Estudantes-Informatica-ISEP/antirecurso)

An exam-preparation platform developed by **NEI-ISEP**, providing students
with exams, results, rankings, study resources and authenticated services.

My work around the project has involved application development,
authentication, infrastructure and integration between services.

---

### 🐧 [Dotfiles](https://github.com/hugo2006alm/dotfiles)

My personal Linux environment and automation project.

What started as configuration files has evolved into a reproducible desktop
setup with automated installation, configuration generation, theming and
service/application reloading through custom tooling.

---

### 🐦 [NatuReal](https://github.com/hugo2006alm/natureal)

A social birdwatching web application developed during **CodeSpring 2024 at
ISEP**, where the project was awarded **1st place**.

It combines challenges, social features, leaderboards and a publication feed
into a complete web application.

---

### 🎮 [SmianSwitch](https://github.com/dinisjcorreia/SmianSwitch)

A team project developed during the **ISEP Game Jam 2024**.

A 2D platformer based around evolution and changing perspective, featuring
multiple movement mechanics, combat, enemies, levels and a final boss fight.
